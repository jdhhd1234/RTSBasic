## 1. 상위 기준과 적용 범위

### 1.1 문서 우선순위

| 출처 | 문서에서 가져오는 내용 |
| --- | --- |
| `Planner/main_plan_spec.md` | 최상위 확정 기획. 장르·플랫폼·기지·승리·운용 단위·대대 목록·보상 |
| `Planner/mvp_contract.md` | MVP 구현 계약. API·WebSocket·좌표계·화면·판정 상세 |
| `server/game/data.py` | 현재 20개 대대, 가격, 계정 성장, 지형·날씨·기지의 초기 밸런스 값 |
| `server/game/sim.py` | 현재 실행되는 이동·상성·피해·보급·영토 처리 |
| 이 문서 | 20개 대대의 수치와 기획을 연결하는 도감, 기획용 비교 항목, 회귀 검증 기준 |

- 상위 기획이 바뀌면 이 문서의 연결 대대와 표현부터 갱신한다.
- 수치가 갱신되면 `data.py`에서 읽은 값으로 대대표, 장비 카드의 참조 능력치, 편성 예시를 함께 갱신한다.
- 사단 방어력은 계약의 편제 합계와 현재 서버의 전투 평균을 구분해 기록한다. 하위 문서가 코드와 계약의 차이를 해소하는 권한은 갖지 않는다.
- 장비 ID `EQ-*`와 구성품 ID `PART-*`는 문서 내부 식별자다. 템플릿과 가챠에는 공식 대대 ID를 쓴다.
- 장비 변형의 게임 효과나 적용 시점이 필요해지면 상위 기획과 구현 계약부터 확정한다.
- 수치의 설계 우선순위는 단순성, 싱글플레이 검증, 서버 권한 순이다.

### 1.3 도감 공개 범위

- 로비의 실제 대대 도감은 공식 대대 20종과 잠금·레벨·능력치·효과를 보여 준다.
- 이 문서의 70종은 대대마다 어떤 실물 장비가 어울리는지 설명하는 카드다.
- 110종은 대표 구성품의 명칭과 소재 태그를 모은 자료다.
- 장비 카드의 능력치와 비용은 연결 대대 Lv.1의 값을 표시한다.
- 장비 카드의 비교 축은 기획자가 살펴볼 대대 필드 하나를 가리킨다. 수치 변경은 서버 데이터의 별도 밸런스 결정이다.
- 재태그는 표기용 작업이다. 생산 재고·장착 슬롯·개별 충전·분대 승하차·공군 레이어의 추가를 수반하지 않는다.

## 2. 자원과 편제

### 2.1 플레이에서 쓰는 자원

| 값 | 단위 | 획득 | 사용 |
| --- | --- | --- | --- |
| 사단 생산 자원 | 경기 내 자원 | 초기 재고, 모든 아군 소유 기지와 영토의 초당 수입 | 편제 템플릿으로 사단 생산 |
| 가챠 포인트 | 계정 포인트 | 적의 군단작전기지·본부 함락 | 대대 해금 또는 강화 |
| 보급 배율 | 사단 전투력 배율 | 가장 가까운 아군 기지까지의 거리를 기준으로 서버에서 계산 | 사단 피해 계산 |
| 장비 자원 태그 | 도감 분류 | 장비 설명 작성 시 지정 | 검색·설명·아트 작업 |

### 2.2 장비 자원 태그 6종

| 태그 | 예시 | 주로 연결되는 대대 |
| --- | --- | --- |
| 금속 | 차체, 견인 장구, 기본 보호판 | 전차·기계화보병·공병 |
| 경량합금 | 기체·경량 차량·수송 프레임 | 공격헬기·수송·정찰 |
| 복합재 | 복합장갑, 보호복, 방호 패널 | 전차·보병·화생방 |
| 기계부품 | 구동계, 정비 공구, 현가 | 정비·수송·전차 |
| 전자부품 | APS, 교신·중계·신호 장치 | 통신·전자전·전차 |
| 광학부품 | 열상, 야간투시, 관측 포드 | 정찰·보병·공격헬기 |

이 태그에는 재고량, 거래, 생산량, 제작 비율이나 추가 원가를 붙이지 않는다. 도감 카드의 생산비는 해당 대대의 `cost` 한 값이다.

### 2.3 경기 내 생산

- 기본 시작 자원은 300이다.
- 템플릿 비용은 대대의 기본 `cost` 합이다. 같은 대대 2개면 비용을 2회 합산한다.
- 성공한 주문에서 자원을 차감하고 사단 1개 생산을 대기열에 넣는다.
- 대기열은 선두 항목부터 진행한다. 사단 하나의 기본 생산 시간은 15초다.
- 완성 시 아군 본부에서 사단을 배치한다. 구현 계약의 대체 배치는 소유 기지를 사용한다.
- 정해진 사단 수 상한은 없다. 증원은 새 사단 생산을 뜻한다.
- 지휘 화면은 현재 자원, 초당 수입, 생산속도, 대기열 진행률을 표시한다.
- 초당 수입은 `1 + 소유 헥스 수 × 0.0015 + 소유 기지 수입의 합`이다.
- AI 수입에는 스테이지와 난이도의 수입 계수를 곱한다.
- 기지 손실과 탈환이 생산속도에 반영된다.

### 2.4 고정 기지

| 기지 | 진영당 | 현재 기본 체력 | 방어력 | 공격력 | 수입/초 | 원소유측 함락 페널티 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| 본부 | 1 | 600 | 40 | 15 | 1.00 | 경기 종료 |
| 군단작전기지 | 2 | 400 | 30 | 12 | 0.50 | 생산속도 ×0.5 |
| 사단작전기지 | 4 | 250 | 25 | 10 | 0.25 | 생산속도 ×0.85 |

- 기지는 위치가 고정된다. 방어가 있는 기지와 교전해 체력을 0으로 만들면 넘어간다.
- 함락 후 체력은 최대의 30%로 시작한다. 원소유측은 다시 교전해 탈환할 수 있다.
- 함락 페널티는 잃은 원소유 기지마다 곱한다. 군단 1곳과 사단 1곳을 잃으면 `0.5 × 0.85 = 0.425`다.
- 같은 상태의 사단 1개 생산 시간은 `15 ÷ 0.425 ≈ 35.29초`다. 서버 틱에서 완료 시간을 확인한다.

### 2.5 편제와 가챠

- 편제는 출격 전 저장한다. 계정 템플릿은 최대 6개다.
- 사단 하나에 대대 1~4개가 들어간다. 같은 대대는 최대 2개다.
- 기본 해금 6종은 즉시 편성 가능하다. 나머지 14종은 계정 해금이 필요하다.
- 가챠는 현금 결제 없이 계정 포인트로 진행한다. 현재 서버의 1회 비용은 100포인트다.
- 현재 보상은 적 군단작전기지 50포인트, 적 본부 200포인트다. 같은 기지는 한 판에 한 번 보상한다.
- 잠긴 대대와 강화 가능한 대대가 함께 남아 있을 때 해금 분기 확률은 40%다.
- 해금 레어도 가중치는 일반 60, 희귀 30, 영웅 10이다. 후보가 있는 레어도끼리 사용한다.
- 강화는 대대 레벨을 올린다. 현재 최대 Lv.10이며 공격력·방어력·체력에 `1 + (레벨 − 1) × 0.05`를 적용한다.
- 사거리, 이동속도, 생산비는 레벨 보정 대상에서 빠진다.
- 해금·강화 결과와 계정 포인트는 서버에 영구 저장한다.

## 3. 실시간 전투와 보급

### 3.1 사단 능력치와 단위

| 값 | 단위 | 판정 기준 |
| --- | --- | --- |
| 공격력 | 점수 | 대대별 레벨 보정 공격력. 전투에서는 각각 사거리와 상성을 평가 |
| 방어력 | 점수 | 편제 합계를 참고. 현재 서버 전투값은 대대 방어력 평균 |
| 이동속도 | km/초 | 편제에서 가장 느린 대대의 속도, 실제 이동에 지형·날씨 적용 |
| 사거리 | km | 편제 참고 표시는 최장 대대 사거리. 공격 가능 여부는 대대별 평가 |
| 체력 | 점수 | 레벨 보정 대대 체력 합으로 사단 최대 체력 결정 |
| 비용 | 경기 생산 자원 | 대대 기본값의 합 |
| 효과 | 서버 효과 키 | 지원대대의 보정. 같은 효과 키는 한 사단에서 1회 해석 |

### 3.2 교전

- 20km 이내에서 만난 적 사단은 자동으로 교전한다. 여러 사단이 한 전투에 참여할 수 있다.
- 사거리 20km를 넘는 대대에는 장거리 사격이 있다. 이동 중에도 서버가 대대별 거리를 판정한다.
- 현재 구현은 날씨를 반영한 대대 사거리의 하한을 교전 반경 20km로 둔다.
- 공격력에는 상성, 사단 체력비, 공격측 지형·날씨, 보급, 편제 효과, 날씨 기반 변동 등이 반영된다.
- 방어에는 현재 서버 기준 대대 방어력 평균, 통신 지원, 방어측 지형을 반영한다.
- 지상 사단의 공격헬기 계열은 `air` 상성 클래스를 사용한다. 방공은 서버 상성표에서 이 계열과 상호작용한다.
- 플레이어 입력은 사단 이동 또는 후퇴에 반영된다. 교전 피해와 목표 판정은 서버가 처리한다.
- 체력이 최대치의 30% 미만으로 떨어지면 자동 후퇴한다. 헌병이 있으면 현재 기준은 20%다.
- 후퇴 중인 사단은 반격하지 않는다. 같은 사단의 다른 대대도 별도 지도 유닛으로 분리되지 않는다.
- 현재 시뮬레이션의 내부 주기는 10Hz다. 아래 수치의 속도·지속·회복 단위는 실시간 초 또는 km다.

### 3.3 지도와 영토

- 지형은 평지·숲·산·강·도시·늪·사막·고원과 통행 불가 바다를 사용한다.
- 사단은 헥스 경로를 따라 지상 이동한다. 수상형 장비의 도감 설명과 바다 통행 판정은 독립적이다.
- 있는 헥스는 사단 기준으로 점령한다. 적이 30km 안에 없으면 인접 헥스 6개도 점령 후보가 된다.
- 서로 다른 진영이 같은 헥스에 동시에 점령을 요구하면 현재 서버는 그 헥스를 보류한다.
- 기지를 함락하면 반경 2헥스까지 영토 변화에 반영한다.
- UI는 소유 진영색과 전선을 함께 그린다. 사단이나 기지의 상태값과 권한은 서버가 보낸다.
- 원본의 확정 승리 조건은 영토가 넓은 쪽이다. 정확한 동률은 원본에 별도 조항이 없으며 현재 코드에서는 AI를 승자로 처리한다.

### 3.4 날씨와 보급

- 날씨는 지역별 맑음·비·눈·안개다. 기본 구현은 4×4 지역에서 60~120초마다 날씨를 바꾼다.
- 비는 이동을 늦춘다. 안개는 사거리를 줄인다. 구체 배율은 서버 스냅샷 표를 사용한다.
- 보급 계산은 가장 가까운 아군 기지까지의 거리로 시작한다.
- 현재 기본 보급은 250km 이내 100%, 650km 이상 50%다. 사이 구간은 선형 보간한다.
- 수송대대 효과가 있으면 계산용 거리를 1.5로 나눈다.
- 수송대대가 없는 450km 사단의 보급은 75%다. 수송 효과를 받는 같은 사단은 적용 거리 300km, 보급 93.75%다.
- 교전 중인 적의 공격력 감소는 전자전대대의 지원 효과로 처리한다.
- 복합장갑·반응장갑·APS의 도감 명칭은 전차 계열 장비 설명에 쓴다. 계산에는 전차대대의 실제 방어력·체력과 기존 상성을 적용한다.

## 7. 편성 예시와 검산

### 7.1 편성별 기본값

모두 대대 Lv.1 기준이다. 공격력 합에는 사거리·상성·날씨를 적용하기 전의 값을 적었다. 전투 방어 평균은 현 서버 계산을 따른다.

| 편성 | 대대 ID | 자원 | 공격 합 | 방어 합 | 전투 방어 평균 | 이동 km/초 | 최장 사거리 km | 최대 체력 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 보병사단 | `inf · inf · arty · eng` | 100 | 42 | 39 | 9.75 | 1.2 | 40 | 350 |
| 기갑사단 | `tank · tank · mech · arty` | 170 | 74 | 51 | 12.75 | 1.2 | 40 | 420 |
| 기계화사단 | `mech · mech · tank · recon` | 145 | 58 | 50 | 12.5 | 2 | 30 | 400 |
| 공격헬기·방공·전자전 예시 | `heli · mech · aa · ew` | 180 | 50 | 34 | 8.5 | 1.6 | 30 | 290 |
| 장거리 보급 예시 | `mech · tank · trans · maint` | 130 | 36 | 41 | 10.25 | 1.8 | 20 | 330 |
| 산악 지원 예시 | `inf · mtn · eng · sig` | 105 | 30 | 42 | 10.5 | 1.2 | 20 | 330 |

- 기본 보병사단, 기갑사단, 기계화사단은 현재 코드의 기본 편제다.
- 공격헬기·방공·전자전 예시의 공식 대대는 각자 해금 상태를 검사한다.
- 사단이 공격헬기대대를 둘 포함하더라도 별도 플레이어 조작 객체는 생기지 않는다.
- 정비·수송은 체력 회복과 보급 계산의 서로 다른 기존 효과다.

### 7.2 단일 대대 레벨 검산

- 전차대대 Lv.3의 강화 배율은 `1 + (3 − 1) × 0.05 = 1.10`이다.
- 전차대대 Lv.3의 공격력은 24.2, 방어력은 17.6, 체력은 132다.
- 사거리 20km, 이동속도 2.2km/초, 비용 50은 유지된다.
- 사단에 같은 전차대대가 2개면 두 대대 각각에 계정의 강화 배율을 적용한다.

### 7.3 사거리와 편제 효과 검산

- 사거리 40km 포병이 안개를 만나면 기본 사거리는 `40 × 0.5 = 20km`다.
- 사거리 30km 공격헬기는 안개에서 곱셈 결과가 15km이고, 현 교전 판정 하한을 적용하면 20km다.
- 전자전대대가 있는 사단의 적이 근접 교전에 들어오면 서버는 적 공격에 0.9배를 적용한다.
- 전자전대대 2개를 담아도 사단 효과 키는 1개다. 대대의 기본 공격력·체력과 비용은 2개를 반영한다.

### 7.4 생산과 회복 검산

- 기갑사단 자원 170 주문을 시작 자원 300에서 한 번 넣으면 주문 직후 자원은 130이다. 경과 시간 수입은 별도로 더해진다.
- 군단작전기지를 하나 잃으면 생산속도 0.5배, 다른 페널티가 없다면 기본 15초가 30초가 된다.
- 의무·정비대대를 함께 편제한 사단은 교전과 피해가 없는 서버 틱에서 최대 체력 기준 1.5%/초를 회복한다.
- 회복 후 사단 체력은 최대 체력까지 제한한다.

- [ ] 대대 0개·5개 템플릿은 거절된다.
- [ ] 같은 대대를 3개 넣은 템플릿은 거절된다.
- [ ] 잠긴 대대를 넣은 플레이어 템플릿은 거절된다.
- [ ] 중복 대대는 가격과 기본 수치에 개수만큼 반영된다.
- [ ] 같은 지원 효과를 지닌 대대 2개가 있어도 현재 서버 효과 키는 한 번만 적용된다.
- [ ] 편제 합계 방어력과 실시간 서버 전투 방어력의 차이를 테스트 기록에서 구분한다.
- [ ] 강화 레벨은 공격력·방어력·체력에 적용되며 이동속도·사거리·생산비는 그대로다.
- [ ] 자원 부족 시 생산 주문이 성공하거나 재고가 음수가 되지 않는다.
- [ ] 군단·사단 기지 함락과 탈환 시 원소유측 생산속도 계수가 바뀐다.
- [ ] 같은 적 기지를 한 경기에서 반복 함락해도 보상은 한 번만 들어온다.
- [ ] 육각 간격은 20km, 근접 교전 시작 반경은 20km다.
- [ ] 공격헬기대대를 넣어도 지도에서 제어하는 객체는 기존 사단이다.
- [ ] 수상 장비를 도감에 표시해도 바다 진입은 금지된다.
- [ ] 장거리 공격, 지역 안개, 근접 반경 하한을 각각 확인한다.
- [ ] 보급 기준 거리 250km와 650km, 수송 편제의 변환 거리를 확인한다.
- [ ] 공병·산악·화생방의 지형 및 날씨 보정을 해당 대대 효과로 검증한다.
- [ ] 전자전 공격력 감소는 근접 범위에 있는 적 사단을 대상으로 확인한다.
- [ ] 체력 임계점에서 기본 사단과 헌병 편제의 자동 후퇴가 구분된다.
- [ ] 상대 본부 함락 또는 정확한 제한 시간 종료로 승패가 결정된다.
- [ ] 먼저 클리어한 스테이지가 계정에 저장된다.
- [ ] 가챠 1회의 결과는 공식 대대 해금 또는 강화 1개다.
- [ ] 플레이어 화면에서 명령이 사단 이동·후퇴·증원으로 연결된다.

### 원본 기획과의 연결

- **장갑**은 복합장갑·반응장갑·능동방호의 차이를 도감에서 설명한다.
- **보병 수송**은 실물 차량의 역할을 설명하고, 게임에서는 기계화보병 및 수송대대 편제로 나타낸다.
- **회전익 장비**는 공격헬기대대의 편제와 구조·수송 실물 참고로 구분한다.
- **보병 관측**은 개인 장구의 예시다. 게임 사거리는 기존 대대와 지역 날씨를 따른다.
- **전자전**은 지원대대 효과를 이해시키는 장비 분류다. 공식 판정은 적 사단의 공격력 보정이다.
